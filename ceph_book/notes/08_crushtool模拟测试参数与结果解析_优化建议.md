# Note 08 优化建议

## 1. 参数拼写修正
- **原文问题**：原文使用了 `--show/utilization` 和 `--showMappings`。
- **优化建议**：根据源码 `src/tools/crushtool.cc`，正确的参数应为：
  - `--show_utilization` (使用下划线，而非斜杠)
  - `--show_mappings` (使用下划线和小写，而非驼峰)
- **影响**：如果用户直接复制原文命令执行，会报错 `unrecognized option`。

## 2. 补充 `--show_utilization_all`
- **原文问题**：原文仅提及 `--show_utilization`。
- **优化建议**：现代 `crushtool` 还支持 `--show_utilization_all`，它会显示所有设备（包括权重为 0 或未选中的设备）的利用率统计，而不仅仅是被选中的设备。这在排查"为什么某些 OSD 没数据"时非常有用。

## 3. 样本量建议
- **原文问题**：原文使用 `100000` 作为样本量。
- **优化建议**：虽然 10 万样本在统计上已经足够，但对于大规模集群（数千 OSD），建议将样本量提高到 `1000000` (100万) 或更高，以更精确地观察长尾分布和极端情况下的数据倾斜。

## 4. 输出格式微调
- **原文问题**：原文输出示例中 `result size == 3: 100001/100001`。
- **优化建议**：确认输出格式是否包含 `x = 0..100000` 这一行。实际输出通常以 `rule 0 (replicated_ruleset), x = 0..100000, numrep = 3..3` 开头。建议保持示例与真实输出高度一致。
